StorePulse Clear Menu Images
=============================

This ZIP replaces the earlier blurry/upscaled menu crops with clear, high-resolution food photography.

Contents:
- 64 named menu image files (4 stores × 8 categories × 2 item slots)
- 8 high-quality category master images
- clear_food_reference_collage.png
- this README

Important:
- Each menu file is a clear category-level placeholder. Items within the same category may share the same image.
- Veg Mania uses a grilled vegetable toast photo as a general placeholder.
- Before production, replace generic placeholders with item-specific photos where appropriate.
- Suggested local web paths: /images/menu/<filename>
- Follow your existing project structure and database schema; do not invent fields or IDs.
